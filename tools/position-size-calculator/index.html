How the calculation works

First, calculate the amount you are prepared to lose if the stop is hit:

Risk amount = account size × risk percentage

Then divide that risk amount by the distance between the entry and stop:

Position size = risk amount ÷ stop distance percentage

For example, a $10,000 account risking 1% has a $100 risk amount. With a stop 2% away, the calculated position value is $5,000.

Important calculation note

This calculator returns a dollar position value. For exchange-traded futures contracts, contract size and tick or point value also determine the correct number of contracts. Confirm the specification for the instrument you trade before placing an order.
